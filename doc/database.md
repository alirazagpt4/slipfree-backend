# Database Schema

MySQL, managed via Sequelize models (no migration files — schema is synced from the model definitions on server start via `sequelize.sync()`, skipped when `NODE_ENV=production`).

## `invoices`

Defined in `models/invoices.model.js`.

| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER (PK) | Auto-generated by Sequelize |
| `receipt_hash` | STRING(64) | Unique. Public identifier used in URLs |
| `invoice_no` | STRING(50) | Unique. POS-supplied invoice number |
| `fbr_invoice_no` | STRING(100) | Optional. FBR (tax authority) invoice number, when present |
| `idempotency_key` | STRING(100) | Unique. Used to dedupe repeated ingest requests |
| `store_id` | INTEGER | Required |
| `shop_name` | STRING(255) | Optional |
| `shop_address` | STRING(500) | Optional |
| `shop_phone` | STRING(50) | Optional |
| `cashier_name` | STRING(255) | Optional |
| `customer_name` | STRING(100) | Optional |
| `customer_phone` | STRING(20) | Optional |
| `price_excl_tax` | DECIMAL(10,2) | Default `0.00` |
| `total_amount` | DECIMAL(10,2) | Required |
| `discount` | DECIMAL(10,2) | Default `0.0` |
| `gst_amount` | DECIMAL(10,2) | Required |
| `pos_fee` | DECIMAL(10,2) | Default `1.0` |
| `payable_amount` | DECIMAL(10,2) | Required |
| `payment_mode` | STRING(100) | Required, default `'Cash'`. Free-form string (not an ENUM) — the Oracle sync path can produce values like `"Split Cash & Credit Card"` |
| `created_at` | DATETIME | Auto (no `updated_at` — invoices are immutable) |

## `invoice_items`

Defined in `models/invoiceItems.model.js`. No timestamps.

| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER (PK) | Auto-generated |
| `invoice_id` | INTEGER | FK → `invoices.id` |
| `product_name` | STRING(255) | Required. Base product name |
| `color` | STRING(50) | Optional |
| `size` | STRING(50) | Optional |
| `item_name` | STRING(255) | Required. Display name, e.g. `"<product> (<color>/<size>)"` |
| `quantity` | INTEGER | Required |
| `unit_price` | DECIMAL(10,2) | Required |
| `gst_percent` | DECIMAL(10,2) | Required |
| `total_price` | DECIMAL(10,2) | Required |

## `invoice_feedback`

Defined in `models/feedback.model.js`.

| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER (PK) | Auto-generated |
| `invoice_id` | INTEGER | FK → `invoices.id`, **unique** (enforces one feedback per invoice) |
| `invoice_no` | STRING(50) | Optional. Denormalized copy of the parent invoice's number |
| `shop_name` | STRING(255) | Optional. Denormalized copy of the parent invoice's shop name |
| `rating` | ENUM(`worst`, `not_good`, `fine`, `good`, `best`) | Required |
| `comment` | TEXT | Optional |
| `submitted_at` | DATETIME | Auto (no `updated_at` — feedback is immutable) |

On submission, feedback is also pushed (fire-and-forget) to an external Oracle `invoice_feedback` table by `services/oracleFeedback.service.js` — a separate table in a separate database, not a Sequelize model.

## `customer_segments`

Defined in `models/customerSegment.model.js`. Not associated with any other model.

| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER (PK) | Auto-generated |
| `segment_name` | STRING(255) | Required |
| `filter_criteria` | JSON | Optional. Arbitrary criteria used to build the segment, not validated/interpreted server-side |
| `customer_list` | JSON | Required, default `[]`. Array of `{ customer_name, customer_phone, feedback }` objects |
| `created_at` | DATETIME | Auto |
| `updated_at` | DATETIME | Auto |

## Relationships

Wired up in `models/associations.model.js`:

- `Invoice.hasMany(InvoiceItem, { foreignKey: 'invoice_id', as: 'items' })` / `InvoiceItem.belongsTo(Invoice, ...)`
- `Invoice.hasOne(Feedback, { foreignKey: 'invoice_id', as: 'feedback' })` / `Feedback.belongsTo(Invoice, ...)`

```
invoices (1) ──< invoice_items (many)
invoices (1) ──1 invoice_feedback (1)

customer_segments  (standalone, no FK relationships)
```
